# Snow-covered foliage (0.1.96)

Snow layers and full snow blocks supported by any leaves tint eligible leaves in the same column at vertical distances 1–8, from 100% white to 12.5% white in equal steps. Air and all leaf types transmit the gradient, including cherry, both azaleas and all poplars, which retain their own colors. Other blocks interrupt it. Snow floating above air is not a source. Near chunks use the block tint provider; the texture, shading and alpha are preserved. Distant captured voxels compute the same steps before horizontal mip reduction. Surface-only previews can show only their represented surface and canopy side, not the complete column. Old mesh fingerprints are invalidated, not the underlying saved voxel data. No per-tick world scan or additional GPU pass is introduced.

Pale oak uses normalized versions of its existing leaf sprites and a fixed 0xA0A69C tint, reproducing the ordinary palette to within one 8-bit channel value and allowing the same white gradient. The near renderer reuses a thread-local mutable position and a precomputed set of eligible leaf blocks.
